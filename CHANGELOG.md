# Changelog

All notable changes to mentor-mode are listed here.

## 0.1.0 - 2026-10-20

### Added
- Write guard: the agent is blocked from writing the learner's code, including shell deletes and formatter rewrites.
- Hint ladder with a dated history of hints, reveals, solves and exams.
- `/mentor kata`: turn a real function from the repo into an exercise.
- `/mentor wrapped`: weekly card written to `.mentor/wrapped.html`.
- Portable `AGENTS.md` for agents without the plugin, generated from `hooks/teaching.ts`.
- Demo GIF in the README.

### Changed
- Line endings normalized to LF across platforms.
